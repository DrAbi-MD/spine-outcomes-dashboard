Transparent by design.

Reproducible data. 240 fictional patients generated in Python using seed 2026. No real patient records are used. Procedure allocation, length of stay, complications, and recovery are illustrative assumptions.

Honest denominators. VAS ranges from 0–10 and ODI from 0–100; lower scores indicate less pain or disability. Each visit uses available records. Paired changes require observed baseline and 6-month scores. Missing values are displayed as “Not recorded”.

Technical scope. Python data generation, JavaScript cohort analysis, SVG charts, responsive interface, and CSV export. No predictive model or clinical recommendation is included.
